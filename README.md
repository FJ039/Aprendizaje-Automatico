# Aprendizaje Automático

## Motivación
Este repositorio está dedicado a mis prácticas y proyectos de Aprendizaje Automático (*Machine Learning*). Considero que esta es una materia esencial para mi formación profesional en Ciencia de Datos. Mi objetivo principal es comprender a fondo los distintos tipos de aprendizaje básico (supervisado, no supervisado y por refuerzo) y descubrir cómo se aplican estos modelos para resolver problemas en el mundo real.
